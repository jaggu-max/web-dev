# JavaScript Learning Folder

This folder organizes the JavaScript topics visible in your APNA College course screenshots. Each topic has:
- a Markdown (`.md`) file with an explanation and example;
- a JavaScript (`.js`) file you can run (the TypeScript topic is explicitly marked as `.ts`).

## How to use
1. Extract this ZIP.
2. Open the `javascript` folder in VS Code.
3. Open a topic's `.md` file to learn and its matching `.js` file to practise.
4. Run a JavaScript file in the VS Code terminal with `node filename.js`, if Node.js is installed.
   Alternatively, copy the code into your browser DevTools Console.
