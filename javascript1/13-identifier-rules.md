# Identifier Rules

## What is an identifier?
An identifier is a name used for a variable, function, or other named item.

### Rules
- Names can contain letters, digits, `_`, and `$`.
- A name cannot start with a digit.
- Names are case-sensitive (`age` and `Age` are different).
- Reserved keywords such as `let` cannot be used as variable names.
- Use meaningful names such as `studentName`.

### Example
```js
let studentName = "Asha";
let _total = 100;
let $price = 50;
console.log(studentName, _total, $price);
```
