# What Is TypeScript?

## What is TypeScript?
TypeScript is a programming language built on JavaScript that adds static type checking. TypeScript code is usually compiled to JavaScript before running.

### Example (TypeScript — save as `example.ts`)
```ts
let studentName: string = "Asha";
let marks: number = 90;
console.log(`${studentName} scored ${marks}`);
```

The `: string` and `: number` annotations help tools detect type mistakes. This example is TypeScript, not plain JavaScript.
