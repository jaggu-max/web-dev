# Numbers in JavaScript

## Numbers
JavaScript's `number` type represents integers and decimal numbers. It also includes special values such as `NaN` and `Infinity`.

### Example
```js
let price = 99.5;
let quantity = 3;
console.log(price * quantity); // 298.5
console.log(Number.isInteger(quantity)); // true
```
