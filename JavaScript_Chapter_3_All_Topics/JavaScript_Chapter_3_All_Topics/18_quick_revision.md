# Chapter 3 Quick Revision

- Array indexes start at `0`.
- `arr.length` gives the number of elements.
- Arrays are mutable: `arr[index] = value` changes an element.
- `const` prevents reassignment of the array variable, not changes to its elements.
- `push()` adds to the end; `pop()` removes from the end.
- `unshift()` adds to the beginning; `shift()` removes from the beginning.
- `indexOf(value)` returns the first index or `-1` if not found.
- `includes(value)` returns `true` or `false`.
- `concat()` combines arrays and returns a new array.
- `reverse()` changes the original array.
- `slice(start, end)` returns a selected portion and does not change the original.
- `splice(start, deleteCount, ...items)` removes/inserts items and changes the original.
- `sort()` sorts values as strings by default; use `(a, b) => a - b` for numeric ascending order.
- Nested arrays contain arrays inside arrays.
- Arrays are reference values; assigning one array variable to another does not create a copy.
