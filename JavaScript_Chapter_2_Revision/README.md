# JavaScript Chapter 2 — Revision Folder

Apna College Sigma 12 JavaScript revision notes and practice code.

## Folders
- `01_Basics_and_Operators/` — console, linking JavaScript, template literals, operators
- `02_Conditionals_and_Logical_Operators/` — if/else, logical operators, truthy/falsy, switch, prompt/alert
- `03_String_Methods/` — trim, immutability, case conversion, indexOf, method chaining, slice, replace, repeat
- `04_Practice_Questions/` — practice solutions

## Run the files
- Run `console.log()` examples in a browser Developer Tools Console or with Node.js.
- Open HTML files in a browser for `prompt()` and `alert()` examples.

## Remember
- String indexes start at 0.
- `slice(start, end)` includes start but excludes end.
- `replace()` with a string search replaces the first match.
- Strings are immutable: methods return new strings.
