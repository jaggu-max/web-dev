# Boolean in JavaScript

## Boolean values
A Boolean has only two values: `true` or `false`. Comparisons usually return a Boolean.

### Example
```js
let isLoggedIn = true;
console.log(isLoggedIn);
console.log(10 > 5);  // true
console.log(10 === 5); // false
```

JavaScript also has truthy and falsy values. Common falsy values include `false`, `0`, `-0`, `0n`, `""`, `null`, `undefined`, and `NaN`.
