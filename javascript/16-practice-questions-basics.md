# Practice Questions: JavaScript Basics

## Questions
1. Which function prints a message to the console?
2. What is the type of `true`?
3. What is the difference between `let` and `const`?
4. What does `typeof 42` return?
5. What is the output of `console.log("JS" + " Rocks")`?

### Answers
1. `console.log()`
2. `boolean`
3. `let` can be reassigned; `const` cannot be reassigned.
4. `"number"`
5. `JS Rocks`
