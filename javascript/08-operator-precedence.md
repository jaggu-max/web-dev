# Operator Precedence

## What is precedence?
Operator precedence determines which operation is evaluated first. Parentheses can make the intended order clear.

### Example
```js
console.log(2 + 3 * 4);   // 14: multiplication first
console.log((2 + 3) * 4); // 20: parentheses first
```
