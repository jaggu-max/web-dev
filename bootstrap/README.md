# Bootstrap Learning Folder

A beginner-friendly Bootstrap practice folder based on the topics covered in the Apna College Bootstrap lessons.

## How to use

1. Open any `.html` file in VS Code.
2. Open it in a browser using Live Server, or double-click the file.
3. Each file is independent and demonstrates one concept.
4. Read the comments in the HTML to understand what each Bootstrap class does.
5. Change text, colors, sizes, columns, and spacing to practice.

## Important Bootstrap classes

- `container` - centered responsive content area
- `container-fluid` - full-width container
- `row` - creates a Bootstrap grid row
- `col-*` - creates grid columns
- `btn` - base button class
- `btn-primary`, `btn-success`, etc. - button variants
- `badge` - small status/count label
- `alert` - notification/message box
- `navbar` - navigation bar
- `card` - content card
- `form-control` - text/email/password input styling
- `form-select` - select/dropdown styling
- `form-check` - checkbox/radio wrapper
- `mb-3` - margin-bottom spacing
- `p-3` - padding
- `text-center` - center text
- `d-flex` - flexbox utility
- `justify-content-*` - horizontal alignment
- `align-items-*` - vertical alignment

## Bootstrap CDN
